# Choosing a Layout

Most shared state has more than one layout atomix can hold. Each row names a
need, the layout that meets it at the least cost, and the chapter that shows it.

| Need                                                            | Take                                                         | Why                                                                       | Chapter                                                                 |
| --------------------------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| Fields that change together, or are read together               | a packed struct in one word                                  | one load reads them whole, one compare-exchange changes them whole        | [Deriving Atom](deriving-atom.md)                                       |
| One field changed alone, often                                  | the field's own operation on the packed word                 | one instruction, no loop: `lock bts`, `lock or`, `lock xadd`, or LSE's    | [Fields](fields.md)                                                     |
| Fields each thread changes on its own, often                    | separate atomics, each on a cache line of its own            | threads that share a line pay for each other's writes                     | [Values and Places](values-and-places.md)                               |
| More than 128 bits changed whole                                | a lock, or a sequence lock over atomics                      | no target has a wider atomic                                              | [A Sequence Lock Over Atomics](a-sequence-lock-over-atomics.md)         |
| Flags or small counts picked by an index at run time            | an array, and an element's place                             | one word; the index's check, then one instruction                         | [Arrays and Element Places](arrays-and-element-places.md)               |
| Small values packed tighter than a slot each                    | a `Packed` array                                             | each element at the bits its range needs, in an integer it states         | [Arrays and Element Places](arrays-and-element-places.md)               |
| Parts that need no names, or that cross an API as a tuple       | a tuple                                                      | a derived struct's layout where each field fills its repr, with no derive | [Tuples and Core's Values](tuples-and-core-values.md)                   |
| A pointer beside a flag, a mark or a small count                | a pointer word: one word, the tags in the alignment's bits   | one word, and the pointer's provenance kept                               | [Tagged Pointers](tagged-pointers.md)                                   |
| A config one thread replaces whole and others read              | an atomic of a shared reference                              | one word; `Acquire` and `Release` held by its type                        | [References and Function Pointers](references-and-function-pointers.md) |
| A hook a thread installs                                        | an atomic of an `Option` of a function pointer               | one word, every ordering, `None` at null                                  | [References and Function Pointers](references-and-function-pointers.md) |
| A pointer beside a version that must not wrap, or two pointers  | two words                                                    | one 16-byte exchange; each pointer's provenance exposed                   | [Two Words](two-words.md)                                               |
| A node beside a version, with strict provenance on every target | an index into an arena beside a version, in one integer word | one word, no pointer, nothing exposed; the arena outlives the structure   | [A Free List](a-free-list.md)                                           |
| 16 bytes many threads read                                      | `load`, with LSE2 or AVX                                     | readers share the line                                                    | [Two Words](two-words.md)                                               |
| 16 bytes read where the target has no 16-byte load              | `load_rmw`                                                   | a compare-exchange, which writes the line, by name                        | [Two Words](two-words.md)                                               |
| A change no instruction makes: a maximum on `x86_64`, a clamp   | `update`, or `try_update` to decline                         | a compare-exchange loop, by name                                          | [What Each Operation Costs](what-each-operation-costs.md)               |
| A value one thread holds alone, as it builds or tears down      | `get`, `set` or `with_mut`                                   | no atomic instruction                                                     | [Values and Places](values-and-places.md)                               |
